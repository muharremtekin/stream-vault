Neden Bu Dil Bu Serviste?
Her dil en güçlü olduğu yerde kullanılıyor — gerçek şirketler de polyglot microservice mimarisini böyle kurar.
⚡

Go — Networking & Concurrency

API Gateway, Streaming ve Search servisleri Go ile. Goroutine'ler sayesinde binlerce eşzamanlı bağlantıyı düşük bellek kullanımıyla yönetir. Netflix'in kendi Zuul gateway'i de benzer pattern'ler kullanır.

🔒

Rust — CPU-Intensive & Safety

Video encoding ve recommendation engine Rust ile. Zero-cost abstraction ile C seviyesinde performans, memory safety garantisi ile crash-free çalışma. FFmpeg binding'leri ile video işleme, ndarray ile ML inference.

🏗️

.NET — Business Logic & CRUD

User, Catalog, Subscription ve Analytics servisleri .NET ile. Entity Framework + Clean Architecture ile hızlı geliştirme. MediatR, FluentValidation gibi mature ekosistem. Gerçek dünyada iş mantığı için ideal.

İletişim
Servisler Arası İletişim Pattern'leri
Gerçek dünya microservice'lerinde en kritik konu: servisler birbirleriyle nasıl konuşur?

Senkron — gRPC

Anlık cevap gereken yerler

Gateway → Servisler arası doğrulama, Streaming → Subscription erişim kontrolü. Proto dosyaları paylaşımlı repo'da tutulur. Deadline propagation ve retry policy ile resilience sağlanır.

Asenkron — Event Bus

RabbitMQ / NATS ile event-driven

ContentUploaded, EncodingCompleted, WatchCompleted gibi domain event'leri. Eventual consistency kabul edilir. Dead letter queue ile hata yönetimi. Outbox pattern ile güvenilir event publishing.

Saga Pattern

Dağıtık transaction yönetimi

Subscription oluşturma: Ödeme al → Abonelik aktifle → Erişim izni ver → Bildirim gönder. Her adım başarısız olursa compensating action çalışır. Choreography-based saga ile loosely coupled.

CQRS + Event Sourcing

Okuma ve yazma ayrımı

Catalog Service'te içerik yazılır (MongoDB) → Event publish → Search Service'te Elasticsearch index güncellenir. Farklı okuma modelleri farklı sorgu ihtiyaçlarını karşılar. Search Service bir read projection'dır.

Core Streaming — Video Pipeline

~2-3 Hafta

Streaming Service (Go) ve Encoding Service (Rust) ekle. Video upload → transcode → HLS segment → serve akışını kur. gRPC ile servisler arası iletişim. RabbitMQ ile event-driven encoding pipeline.

gRPC + Proto RabbitMQ HLS Streaming FFmpeg MinIO Async Pipeline
3

Smart Features — Arama, Öneri, Abonelik

~2-3 Hafta

Search Service (Go + Elasticsearch), Recommendation Engine (Rust) ve Subscription Service (.NET) ekle. CQRS pattern, Saga pattern, collaborative filtering. Sistemin "akıllı" hale gelmesi.

Elasticsearch CQRS Saga Pattern Collaborative Filtering Outbox Pattern
4

Production-Ready — Observability & Resilience

~1-2 Hafta

Notification Service, distributed tracing (Jaeger), metrics (Prometheus + Grafana), centralized logging (ELK), health checks, circuit breakers. Chaos testing ile sistemin dayanıklılığını test et.
